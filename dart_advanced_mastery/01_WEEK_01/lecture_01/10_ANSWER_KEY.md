## 2. نموذج إجابة الواجب المنزلي (Homework Solutions)

### القسم الأول: الفهم النظري (أسئلة 1 - 5)
1. **JIT vs AOT:** في الـ JIT يتم تجميع الكود تدريجياً أثناء التشغيل مما يتيح التعديل الفوري Hot Reload وسرعة دورة التطوير، بينما في AOT يُترجم الكود كاملاً لكود آلة قبل التوزيع لضمان أقصى سرعة إقلاع وتشغيل وحماية الكود في الـ Release.
2. **الخاصية الرياضية:** Dart تطبق نظاماً مغلقاً رياضياً (Sound Type System) حيث يُثبت المترجم عدم إمكانية احتواء أي مرجع غير قابل للـ null على قيمة null، على عكس لغات أخرى تسمح بتجاوز الأنواع عبر `any`.
3. **Canonicalization:** تخزين نسخة وحيدة وموحدة من الكائنات الثابتة في الـ Constant Pool بالذاكرة؛ مما يعني أن تكرار إنشاء كائنات const متطابقة لا يستهلك أي بايت إضافي في الـ Heap ولا يشغل الـ Garbage Collector بتنظيفها.
4. **فشل الـ Promotion في Class Fields:** لأن الحقل العام غير الـ final قد يتم استدعاء Getter خاص به في ثريد أو دالة أخرى يعيد قيمة null بعد إجراء فحص الـ if مباشرة، فلا يستطيع المترجم ضمان ثباته.
5. **دور Never:** يخبر المترجم بأن مسار التنفيذ هذا ينتهي حتماً برمي Exception أو حلقة لا نهائية، مما يساعد الـ Flow Analyzer على حذف أي كود يقع بعده كـ Dead Code وترقية المتغيرات في المسارات البديلة.
