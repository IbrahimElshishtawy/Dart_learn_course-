# Student Study Guide — دليل المتدرب للتعلم والتفوق

## مرحباً بك في رحلة احتراف Dart: من الصفر المطلق إلى التأسيس الهندسي 🚀

أهلاً بك! إذا كانت هذه هي المرة الأولى التي ترى فيها كود برمجي أو تسمع بلغة Dart، فأنت في المكان الصحيح تماماً.  
تمت هندسة هذا المنهج بحيث **لا يفترض امتلاكك لأي معرفة برمجية سابقة**. سنبدأ معك خطوة بخطوة من الصفر الحقيقي، ونبني عقليتك وتفكيرك المنطقي والحاسوبي تدريجياً.

---

## 0. خريطة المبتدئ: كيف تبدأ دون أن تشعر بالارتباك؟ (Zero-Knowledge Onboarding)

1. **البرمجة ليست حفظاً:** لا تحاول حفظ الأكواد إطلاقاً! البرمجة مثل قيادة الدراجة؛ تُتعلم بالممارسة والتدريب الحركي على لوحة المفاتيح.
2. **سلم التعلم التساعي:** كل مفهوم ستدرسه سيمر بـ (تشبيه حياتي $\rightarrow$ شرح بسيط $\rightarrow$ رسم بصري $\rightarrow$ كود من 3 أسطر $\rightarrow$ تتبع باليد $\rightarrow$ مثال متوسط $\rightarrow$ مثال متقدم $\rightarrow$ تطبيق عملي $\rightarrow$ تمرين مستقل).
3. **لا تقلق من المصطلحات المعقدة:** موضوعات الكورس مقسمة إلى:
   - 🟢 **Core Learning:** ركز عليها وطبقها بنفسك؛ هذه هي قلب البرمجة الأساسي (متغيرات، شروط، حلقات، دوال، كلاسات).
   - 🟡 **Introduction:** افهم فكرتها العامة.
   - 🔵 **Advanced Exposure** و 🟣 **Future Learning:** هذه موضوعات للمستقبل والاطلاع المعماري لترى أين ستصل مستقبلاً أثناء احتراف Flutter؛ لا تشغل بالك بإتقانها في الأسبوع الأول!

## 1. تجهيز بيئة العمل القياسية (Industrial Environment Setup)

لتشغيل جميع مشاريع وأكواد الكورس بأقصى كفاءة:

1. **تثبيت Dart SDK:**
   - تأكد أن لديك Dart بإصدار `3.8.1` أو أحدث:
     ```bash
     dart --version
     ```
2. **محرر الأكواد الموصى به (VS Code أو Android Studio):**
   - تثبيت إضافة **Dart** الرسمية.
   - تفعيل خيار `Format on Save` في الإعدادات.
3. **ضبط قواعد التحليل الصارم (Strict Static Analysis):**
   - سنعتمد على ملف `analysis_options.yaml` قوي يفعل القواعد الصارمة:
     ```yaml
     include: package:lints/recommended.yaml

     analyzer:
       language:
         strict-casts: true
         strict-inference: true
         strict-raw-types: true
       errors:
         missing_required_param: error
         missing_return: error
         todo: ignore
     ```

## 2. استراتيجية المذاكرة الفعالة (The Active Engineering Learning Method)

لا تقرأ الكود مثل الروايات الأدبية! البرمجة مهارة حركية عقلية:

1. **الخطوة الأولى: الفهم المجرد (Concept Exploration)**
   - اقرأ التمهيد والسيناريو الحياتي للمفهوم.
   - افهم لماذا تم ابتكار هذا المفهوم في علوم الحاسب وما هي المشكلة التي يحلها.
2. **الخطوة الثانية: كتابة الكود يدوياً (Do Not Copy-Paste)**
   - افتح الـ Editor واكتب الكود بيدك من البداية.
   - انتبه لرسائل الـ IDE والمترجم (Compiler Inferred Types) عند الوقوف بالماوس فوق المتغيرات.
3. **الخطوة الثالثة: كسر الكود عمداً (Intentional Sabotage)**
   - بعد أن يشتغل الكود بنجاح، جرب تغييره:
     - ماذا لو مررت قيمة `null`؟
     - ماذا لو حذفت كلمة `const`؟
     - ماذا لو غيرت نوع الـ Return type إلى نوع آخر؟
   - تعلم قراءة رسائل الأخطاء في Dart؛ المترجم هو أفضل معلم لك.
4. **الخطوة الرابعة: حل المسائل الخوارزمية (Stanford-Style CS Practice)**
   - لا تنظر إلى الحلول!
   - خصص من 30 إلى 45 دقيقة لكل مسألة.
   - اكتب الخوارزمية بالورقة والقلم، وحدد الـ Edge Cases والـ Time/Space Complexity قبل كتابة كود Dart.

## 4. ميثاق الشرف الأكاديمي والنزاهة البرمجية

- جميع ملفات `10_ANSWER_KEY.md` وضعت للمساعدة بعد استنفاد كل المحاولات الفردية.
- استخدام الذكاء الاصطناعي لكتابة الواجب نيابة عنك لن يعلمك شيئاً وسيكشفه الاختبار الشامل العملي ومشروع التخرج.
- استخدم الذكاء الاصطناعي كـ **Rubber Duck Debugger** لمناقشة الأفكار وتوضيح الغموض وليس لنسخ الحلول الجاهزة.

## 5. كيف تستعد لمشروع التخرج النهائي (Dart Modular Engineering Core)؟

- كل محاضرة تبني طوبة أساسية ستستخدمها في مشروع التخرج.
- عندما تتعلم الـ Records في المحاضرة 3، ستحتاجها في نمذجة الـ Entities.
- عندما تتعلم الـ Generics في المحاضرة 6، ستستخدمها في بناء الـ Repository Layer.
- عندما تتعلم الـ Streams والـ Isolates في الأسبوع الثالث، ستبني بهما محرك معالجة الأحداث والمهام الثقيلة.
- احتفظ بمكتبة كود منظمة تضم الدوال النظيفة التي تبنيها أثناء الكورس لتستفيد منها لاحقاً.
