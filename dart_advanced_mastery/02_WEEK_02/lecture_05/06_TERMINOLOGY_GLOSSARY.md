# Lecture 05: Terminology Glossary
# قاموس المصطلحات التقنية - المحاضرة 5

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح الدقيق للمبتدئ |
|:---|:---|:---|
| **Inheritance** | الوراثة | آلية تسمح لكلاس فرعي (Subclass) باكتساب خصائص ودوال كلاس أساسي (Superclass) لإعادة الاستخدام. |
| **Abstract Class** | فئة مجردة | كلاس صُمم ليكون نموذجاً أولياً وعقداً فقط، ولا يمكن إنشاء كائن مباشر منه بواسطة `new` أو الاستدعاء العادي. |
| **Abstract Method** | دالة مجردة | إعلان دالة بدون كود تنفيذي (فقط اسم ومدخلات ونوع إرجاع) تُلزم الأبناء بكتابة تفاصيلها. |
| **Interface** | واجهة العقد البرمجي | مجموعة من المواصفات والدوال التي تعد الفئة بتقديمها دون فرض طريقة التنفيذ الداخلية. |
| **Implicit Interface** | واجهة ضمنية | خاصية فريدة في Dart تجعل كل كلاس يتم تعريفه بمثابة واجهة يمكن تطبيقها عبر `implements`. |
| **Polymorphism** | التعددية الشكلية | قدرة البرنامج على معاملة كائنات مختلفة بطريقة موحدة استناداً إلى الواجهة المشتركة التي تجمعهم. |
| **Composition** | التركيب والدمج | تجميع كائنات وسلوكيات مستقلة داخل كائن أكبر (علاقة Has-A) بدلاً من وراثتها في شجرة صلبة (Is-A). |
| **Method Overriding** | تجاوز / إعادة تعريف الدالة | إعادة كتابة كود دالة موروثة من الفئة الأم باستخدام الكلمة الدلالية `@override`. |
| **Super Keyword** | الكلمة الدلالية super | مرجع يُستخدم داخل الكلاس الفرعي للوصول إلى دوال ومنشئ الفئة الأم المباشرة. |
| **Fragile Base Class** | مشكلة الفئة الأم الهشة | عيب معماري يحدث عند تعديل الفئة الأم فيتسبب التعديل في انهيار أو كسر سلوك الفئات المشتقة منها. |
