### السؤال 1 (اختيار من متعدد)
ما الغرض الأساسي من استخدام `_` قبل اسم الحقل في كلاس Dart؟
- [ ] أ) جعله ثابتاً غير قابل للتعديل.
- [ ] ب) جعله خاصاً (Private) داخل نفس المكتبة/الملف.
- [ ] ج) تسريع أداء الوصول للحقل في الذاكرة.
- [ ] د) تحويله تلقائياً إلى Getter و Setter.

### السؤال 2 (اختيار من متعدد)
ما الفرق الرئيسي بين دالة المنشئ `factory` والمنشئ العادي (Generative Constructor)؟
- [ ] أ) المنشئ الـ `factory` لا يمكن أن يقبل معاملات.
- [ ] ب) المنشئ الـ `factory` يستطيع إرجاع كائن موجود مسبقاً (Cache) أو كائن من نوع فرعي.
- [ ] ج) المنشئ الـ `factory` يعمل فقط في وقت الترجمة (Compile-time).
- [ ] د) لا يوجد أي فرق عملي بينهما.

### السؤال 4 (تتبع الكود)
ما ناتج تنفيذ الكود التالي؟
```dart
class Point {
  final int x, y;
  const Point(this.x, this.y);
}

void main() {
  final p1 = Point(1, 2);
  final p2 = Point(1, 2);
  print(p1 == p2);
}
```
- [ ] أ) true
- [ ] ب) false
- [ ] ج) Compilation Error
