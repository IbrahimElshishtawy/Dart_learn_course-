## 💬 1. المناظرة البرمجية: Mutable State vs Immutable State
- **الموقف**: مبرمج يقول: "أنا ليه أعمل كلاس غير قابل للتعديل وأقعد أعمل دالة `copyWith` في كل مرة أحب أغير حقل واحد؟ طب ما أخليه `var` وأعدل على طول وخلاص!".
- **سؤال النقاش**:
  - ما هي المخاطر الحقيقية لتعديل كائن مشترك (Shared Mutable State) في تطبيق كبير؟
  - كيف تحمي الـ Immutability مطور واجهات Flutter من مشاكل إعادة بناء الشاشات وإعادة الرسم (Rebuilding/Re-rendering) غير المتوقعة؟

## 💬 2. فحص الهوية والذاكرة: identical() vs operator ==
- **الموقف**:
  ```dart
  class User {
    final String id;
    const User(this.id);
  }
  
  final u1 = User('10');
  final u2 = User('10');
  const u3 = User('10');
  const u4 = User('10');
  ```
- **سؤال النقاش**:
  - هل `u1 == u2` تعطي `true` أم `false`؟ ولماذا بالرغم من تطابق الـ `id`؟
  - ما الذي يحدث في ذاكرة الـ Dart VM يجعل `identical(u3, u4)` تعطي `true` بينما `identical(u1, u2)` تعطي `false`؟
