# Lecture 04: Terminology Glossary
# قاموس المصطلحات التقنية - المحاضرة 4

| المصطلح بالإنجليزية | المصطلح بالعربية | الشرح الدقيق للمبتدئ |
|:---|:---|:---|
| **Class** | الفئة / نموذج التفصيل | القالب أو المخطط النظري (Blueprint) الذي يحدد خصائص وسلوك الكائنات. |
| **Object / Instance** | الكائن / النسخة الواقعية | الكيان الفعلي المحجوز في الذاكرة المبني طبقاً لنموذج الـ Class. |
| **Constructor** | دالة البناء / المنشئ | دالة خاصة تنفذ تلقائياً عند ولادة الكائن لتجهيز حقوله وقيمه المبدئية. |
| **Named Constructor** | منشئ مسمى | منشئ إضافي يحمل اسماً معبراً لأداء غرض معين مثل `User.guest()` أو `User.fromJson()`. |
| **Factory Constructor** | منشئ المصنع | منشئ لا ينشئ بالضرورة كائناً جديداً، بل يمكنه إرجاع كائن مخزن مسبقاً (Cache) أو نوع فرعي. |
| **Encapsulation** | التغليف وحماية البيانات | إخفاء التفاصيل والحقول الحساسة خلف `_` وجعل التفاعل يمر فقط عبر دوال آمنة. |
| **Immutability** | عدم القابلية للتعديل | مبدأ تصميم الكائنات بحيث لا يمكن تغيير أي حقل فيها بعد لحظة إنشائها. |
| **Identity vs Equality** | الهوية مقابل المساواة | الهوية تعني هل يشيران لنفس المكان في الذاكرة (`identical`)، والمساواة تعني هل يحملان نفس القيم الهيكلية (`==`). |
| **Canonical Instance** | النسخة الموحدة المعتمدة | الكائنات الثابتة `const` التي يدمجها Dart VM في مرجع واحد بالذاكرة لتوفير المساحة. |
| **CopyWith Pattern** | نمط النسخ مع التعديل | دالة تنتج نسخة جديدة ومعدلة من كائن غير قابل للتعديل دون المساس بالأصل. |
