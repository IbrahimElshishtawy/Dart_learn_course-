# Lecture 04: References & Further Reading
# المراجع والمصادر التوثيقية - المحاضرة الرابعة

## 📚 المصادر الرسمية والأكاديمية
1. **Dart Official Language Tour - Classes**:
   - التوثيق الرسمي الشامل لإنشاء الكلاسات والمنشئات في Dart 3.
   - [Dart Docs: Classes & Objects](https://dart.dev/language/classes)
2. **Effective Dart: Design & Style Guide**:
   - إرشادات فريق لغة Dart لتسمية المنشئات، واستخدام الـ Factory Constructors، وحماية الحقول.
   - [Effective Dart: Design](https://dart.dev/effective-dart/design)
3. **Dart Language Specification**:
   - القسم الخاص بـ Operator Overloading و Equality Contracts (`identical`, `==`, `hashCode`).
4. **Clean Code & Domain-Driven Design (Eric Evans & Martin Fowler)**:
   - مفهوم الـ Value Objects ونمط عدم القابلية للتعديل (Immutability) وتطبيقه في بنية التطبيقات الحديثة.
